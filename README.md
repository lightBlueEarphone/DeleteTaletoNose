# README

## 消去しりとり（DeleteTaletoNose）

五十音を持ち駒として使うしりとりゲームです。

- CPU対戦
- ローカル対戦
- 先頭の文字は前の単語の末尾を引き継ぐ
- 「ん」で終わる単語を言うと負け
- 1回使った駒は二度使えない
- 持ち駒がなくなれば勝利
- 持ち駒で作れる単語がなくなれば敗北
- WikipediaまたはWiktionaryのページの読みをソートキーから取得する（インターネット接続が必要）
- リダイレクト先と曖昧さ回避ページも単語として扱う

## 実行方法

```bash
npm install
npm run dev -- --host 0.0.0.0
```

ブラウザで表示されたURLを開いて遊んでください。

## ルールメモ

- 最初の単語は自由に決められます。
- 2回目以降は、前の単語の最後の文字で始める必要があります。
- 単語中の先頭文字は引き継ぎの文字として消費されません。
- そのほかの文字は、自分の持ち駒から使う必要があります。
- 清音と濁音は同じ拍として扱い、濁音は清音に変換して判定します。

## 補足

本リポジトリでは、リアルタイムオンライン対戦の実装までは含めていません。まずは対戦しやすいローカル対戦とCPU対戦を動く状態にし、将来的にWebSocketやバックエンドを足してオンライン対戦へ発展できるようにしています。
